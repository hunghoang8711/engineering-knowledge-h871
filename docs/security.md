# Security checklist

- [ ] Confirm whether this GitHub repository should remain public.
- [ ] Never upload customer drawings, source documents, passwords, tokens, or confidential project information to this repository.
- [ ] Use a dedicated database project for Engineering Knowledge Hub.
- [ ] Enable authentication and Row Level Security (RLS) before storing company information.
- [ ] Test that unauthenticated users cannot read private records and viewer accounts cannot write.
- [ ] Never place a service-role key in frontend code or any public repository.
- [ ] Keep original files in an approved company location and apply its access controls.
- [ ] Back up database records and source files independently.
- [ ] Confirm company approval before sending confidential data to NotebookLM, Gemini, or any external AI service.
- [ ] Keep AI-generated records separate from verified records and retain source citations.
